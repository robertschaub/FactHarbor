#### Diagnosis (as revised after independent review)

- **Cause 1, wording admits a narrow true reading — plausible; its effect size and dominance are not isolated.** VBS-page sentence 72 % (R3) versus sharpened wording 30 % (R1) and 52 % (R2); production 65 % and 88 %. Confounds: one run per condition, article context, unverified production runtime, differing `primaryMetric` emphasis (R2), a failed atomicity-validation call (R2). Routing is by prompt design: the scope-of-truth rule sends omitted qualifications to per-claim `misleadingness` (no article-level field; the narrative key finding also states the mismatch). The flag fired in every run.
- **Cause 2, retrieval dominated by government pages — not reproduced locally; the real losses were structural (code-confirmed, now fixed or surfaced):** (1) `filterClaimUnderstandingForSelectedClaims` deleted every preliminary item without a selected claim id before the remap/seed fallbacks (introduced with auto-selection, `d2d06f839`, 2026-05-24); (2) `fetchSources` skipped URLs already fetched in Stage 1, so they were never extracted against the final claims although ranked first in Stage 2; (3) the relevance gate scored contradicting official sources 0.10–0.20 in one R2 refuting pass (classifier receives neither iteration intent nor `expectedEvidenceProfile`; one episode in 74 discard blocks); (4) no prior-query memory in `generateResearchQueries`; (5) weekly freshness windows on 2024/2025 dispute queries; (6) no query ever targeted the audit office; (7) per-target evidence attribution; (8) GAO/CBO reports capped as `foreign_reaction` in R4. Domain counts: official domains 8 of 42 raw (R1), 60 of 254 (R3).
- **Cause 3, language — different source composition observed; causality is not isolated.** EN input: 1 Swiss-media raw result of 70, no Swiss media in the pool, one Swiss source (admin.ch English release), manufacturer page selected five times. R1 was LEANING-FALSE (30 %) and R2 MIXED (52 %), although both were `highly_misleading`. Both language lanes off; source-native lane is a no-op scaffold.

Independent review (Codex, prompt in `test-output/review/`): C4 holds; C1, C2, C3, C5, C6, C8, C9, C11 partially hold; C7 ("wording dominant") and C10 ("flag is the only carrier") refuted as stated; C12 ("material issues missed") holds. Corrections are recorded above and in the open items (stale meta count, R3 integrity cap, R2 Swiss source, R1 contradiction yield, extractor example id `AC_01`, reliability lookups 190/169/326/330 rows, narrative claim-count drift, direction rescue override). The review confirmed the lossy selection path but could not reconstruct every pre-filter payload; it did not prove that every preliminary extraction lacked a usable claim ID.
