## Diagram Pattern

Shared diagrams use canonical Mermaid source and rendered SVG assets. Link to both so readers can inspect the source and open a full-size image.

New diagrams should follow this pattern. Always use Mermaid syntax (not images) so diagrams remain editable and version-controlled. See DOC-R-028 for Mermaid syntax rules (empty lines required before/after the mermaid block).
