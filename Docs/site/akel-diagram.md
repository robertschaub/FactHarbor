# Analysis method diagram

![Claims become an evidence-backed report through research, boundaries and debate](diagrams/homepage-method.svg)

[Full-size diagram](diagrams/homepage-method.svg) · [Mermaid source](diagrams/homepage-method.mmd)

The diagram retains FactHarbor's existing homepage explanation: identify verifiable claims, research supporting and opposing evidence, assess quality, organise evidence-defined boundaries, and use distinct debate roles before reporting an assessment.

Read the [analysis architecture](akel-pipeline.md) and [stage responsibilities](akel-stage-details.md) for the public explanation. The diagram shows the method; it does not assert a fixed internal call sequence or budget.
