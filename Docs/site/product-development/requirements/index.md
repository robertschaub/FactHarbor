# Requirements

**FactHarbor translates user needs into a verifiable, automated system through strict quality standards.** We prioritize **system-over-data**—fixing the algorithm rather than the individual output. This ensures that every analysis is evidence-based, neutral, and auditable.

## Visual Reference: The User Experience

Requirements are best understood through the intended user experience. Below are the key UI patterns defined by these requirements.

### 1. Side-by-Side Analysis (FR12)

Provides an immediate comparison between the source document and FactHarbor's evidence-based findings.

### 2. In-Article Highlighting (FR13)

Real-time credibility indicators overlayed on the text.

**Researchers found that Mediterranean diet followers had a 25% lower risk of heart disease** ↑ WELL SUPPORTED • 87% confidence

**Some experts believe this diet can completely prevent heart attacks** ↑ UNCERTAIN • 45% confidence — Overstated based on evidence
